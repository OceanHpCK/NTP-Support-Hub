# UI/UX Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refresh NTP Support Hub Phase 1 UI toward a bright, clean, professional technical SaaS style.

**Architecture:** Keep the existing React/Vite/Tailwind architecture and registry-driven app routing. Apply shared visual language directly in touched shell/dashboard files and use PolyWeld Butt Fusion as the first calculator template without changing formulas.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind CSS utilities, lucide-react, recharts.

## Global Constraints

- Use existing React, TypeScript, Vite, Tailwind CSS, lucide-react, and recharts dependencies.
- Do not add a UI framework.
- Keep changes scoped to shared shell/dashboard files and PolyWeld Butt Fusion files for Phase 1.
- Keep formulas unchanged.
- Preserve accessibility basics: focus states, semantic labels, readable contrast, and mobile usability.
- Do not use decorative background blobs or overly ornamental elements.
- Refresh `server/public` from `dist` and deploy Cloudflare Worker after build.
